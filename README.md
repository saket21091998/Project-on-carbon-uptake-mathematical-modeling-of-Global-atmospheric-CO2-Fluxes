# Project-on-carbon-uptake-mathematical-modeling-of-Global-atmospheric-CO2-Fluxes
Project on carbon uptake trend decomposition mathematical modeling of Global atmospheric CO2 Fluxes
Objective: Modeling seasonal biospheric \text{CO}_2 uptake and testing forest disturbance sensitivity via ODEs.
 Methods: Non-linear least-squares curve fitting (⁠scipy.optimize⁠) and numerical ODE integration (⁠scipy.integrate.solve_ivp⁠) on NOAA time-series data.
 Key Takeaway: Demonstrates how seasonal vegetation uptake drives intra-annual \text{CO}_2 oscillations and how temporary sink disturbances create lasting atmospheric \text{CO}_2 anomalies.
